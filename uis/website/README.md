# TrackFlow Website

Sitio estático de TrackFlow, compatible con Codespaces y servido desde esta carpeta.

## Ejecutar localmente

Desde `uis/website`, ejecuta:

```bash
npx --yes serve . --listen 8000
```

Abre `http://localhost:8000`. En Codespaces, reenvía el puerto `8000` y cambia su visibilidad a **Public** desde la pestaña **Ports** para obtener una URL accesible externamente.
